GAINZ Sherpa — Product Specification

PWA v0.1 · Installable on iOS Safari · No backend

1. Overview

GAINZ Sherpa is a Progressive Web App that uses the device's geolocation and compass to point the user toward the nearest public gym and show the distance in their preferred units. Gyms are discovered dynamically via the Google Maps Places API. Installable to the iOS home screen, launches full-screen in standalone mode. No accounts, no backend — the app shell and last-known gyms are cached locally for offline use.

2. Target Audience

Gym-focused users who want the fastest, no-friction way to locate and orient toward the closest public gym while out and about — no map clutter, just a direction and a distance.

3. Core Features

📍 GeolocationReads position via the Geolocation API and queries Google Maps Places for nearby gyms.
🧭 Live CompassA large arrow rotates to point toward the nearest gym using device heading.
📏 Distance ReadoutBig, glanceable distance updating in real time as the user moves.
⚙️ Unit ToggleSwitch between miles and kilometers; choice persists between sessions.

4. Functional Requirements

  • On launch, request location and compass permissions with clear explanation.
  • Query the Google Maps Places API (type=gym) around the user's position.
  • Compute great-circle distance (Haversine) to each discovered gym.
  • Highlight the nearest gym; rotate compass arrow to its bearing relative to device heading.
  • Display distance in user-selected unit (miles or kilometers).
  • Recompute continuously as position/heading change; re-query Places on meaningful movement.
  • Cache latest Places results for offline fallback.
  • Gracefully handle denied permissions, no signal, failed API calls, and no nearby gyms.

5. Engagement & Retention

  • Instant payoff — arrow + distance appear within seconds, no setup.
  • Bold motivational visual identity (dark theme, hype copy).
  • Streaks & proximity check-ins — count gym visits, keep a local streak.
  • Haptic/visual cue when closing in on the gym.
  • Rotating hype phrases for personality.

7. PWA & iOS Behavior

  • Add to Home Screen installs with custom icon, launches standalone.
  • Service worker enables offline-first launch.
  • iOS requires user gesture for compass permission — handled by a tap gate.

8. Deployment

  • GitHub Pages with custom domain (gainz.messana.ai), HTTPS enforced.
  • API key stored as GitHub Actions secret, injected into git-ignored config.js at deploy.
  • Bump service worker cache version on each release.

9. Parallelism

  • Geolocation + compass listeners start in parallel on launch.
  • Places query fires on first position fix, concurrent with rendering.
  • Heavy computation can be offloaded to a Web Worker.

10. Privacy

  • Coordinates sent only to Google Maps Places API. No other data leaves the device.
  • All local data in localStorage. No accounts, no tracking.

11. Out of Scope

  • User accounts, social feeds, cloud sync.
  • Turn-by-turn navigation.
  • Real-time crowd or gym-hours data.
